# Analyses examined but not reported

This directory contains exploratory analyses performed during manuscript
development that are **not used as evidence for any quantitative claim
in the manuscript**. They are retained for transparency and to document
analyses that were examined but not carried forward.

## Allele-association exploration

`allele_association/` contains the allele summaries produced in section
(B) of the donor QC outputs. These analyses were not reported because
the direction of the apparent allele association was not consistent
across donors and because OAS allele assignments are repertoire
annotations rather than genomic genotypes. In addition,
mutation-dependent allele assignment can confound an association
analysis involving K31E. No genotype or allele association is claimed in
the manuscript.

## HCDR3 motif search

`hcdr3_motif_search/` contains an exploratory search for HCDR3 sequence
motifs related to motifs described in VITT-associated antibodies. This
analysis was not reported because the observed enrichment was small and
the motif was rare within the DDS(D)-proxy paired subset; a longer motif
also partly recapitulated IGHJ3 germline sequence. These outputs are
therefore retained as exploratory work only and are not used to support
manuscript conclusions.

The presence of a file in this directory should not be interpreted as a
reported result or as independent evidence for a manuscript claim.
